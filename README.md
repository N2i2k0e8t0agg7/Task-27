# React Shopping Cart UI
A simple React shopping cart application built for practice and learning React fundamentals.  
This project displays products, allows users to add items to a cart, manage quantities, and automatically calculates the total price.

## Features
- Product listing UI
- Add to Cart functionality
- Increase / decrease item quantity
- Remove item when quantity becomes zero
- Dynamic total price calculation
- Responsive card-based layout
- Styled using Tailwind CSS

## Technologies Used
- React
- JavaScript
- Tailwind CSS
- Vite

## Concepts Practiced
This project helped in understanding:

- React Components
- JSX
- useState Hook
- Array methods:
  - map()
  - reduce()
  - filter()
- Event handling
- State updates
- Conditional rendering
- Dynamic UI rendering
